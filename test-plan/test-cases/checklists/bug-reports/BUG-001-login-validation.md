# BUG-001 — Login validation

## Title

Error message is not displayed when login fields are empty.

## Environment

- OS: Windows
- Browser: Google Chrome

## Preconditions

Login page is opened.

## Steps to Reproduce

1. Open the Login page.
2. Leave the username field empty.
3. Leave the password field empty.
4. Click the Login button.

## Expected Result

Validation messages should be displayed for required fields.

## Actual Result

No validation message is displayed.

## Severity

Medium

## Priority

High

## Status

Open
