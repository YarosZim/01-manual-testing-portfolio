# Test Plan

## 1. Introduction

This document describes the testing approach for the demo e-commerce application.

## 2. Test Objective

The main objective is to verify that users can successfully:

- register an account;
- log in;
- browse products;
- search for products;
- add products to the cart;
- modify cart contents;
- complete checkout;
- log out.

## 3. Scope

### In Scope

- Registration
- Login
- Product catalog
- Product search
- Shopping cart
- Checkout
- Logout

### Out of Scope

- Performance testing
- Security testing
- Database testing
- Third-party payment provider testing

## 4. Test Types

- Functional testing
- Regression testing
- Smoke testing
- Exploratory testing
- Positive testing
- Negative testing
- Usability testing

## 5. Test Environment

Browser: Google Chrome

Operating System: Windows

## 6. Test Data

Test accounts and product data will be used during testing.

## 7. Entry Criteria

Testing can start when the application is available and the main functionality is implemented.

## 8. Exit Criteria

Testing can be completed when all planned test cases have been executed and critical defects have been addressed.

## 9. Risks

- Application instability
- Incomplete requirements
- Environment issues
- Unavailable test data
